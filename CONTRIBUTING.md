# Contributing to Awesome Codebase Intelligence

Thank you for contributing! This list aims to be the most comprehensive resource for codebase intelligence tools, research, and practices.

## Guidelines

### Adding a New Tool or Resource

1. Fork the repo
2. Add your item to the appropriate category in `README.md`
3. Use the format: `- [Name](URL) - Description.`
4. Keep descriptions under 20 words
5. Place items alphabetically within their category
6. Submit a pull request

### Quality Standards

- **Tools** must be actively maintained (commit within last 12 months) or historically significant
- **Research** must be from credible institutions, peer-reviewed, or widely cited (100+ citations)
- **Communities** must have active membership (posts within last 30 days)
- No affiliate links, referral codes, or tracking parameters in URLs
- Commercial tools should have a free tier, trial, or open-source alternative noted

### What Doesn't Belong

- General-purpose IDEs (VS Code, IntelliJ) unless they have codebase intelligence-specific features
- Generic project management tools (Jira, Linear) unless they have code-aware features
- Marketing content disguised as resources
- Tools that have been deprecated with no maintained fork

### Suggesting a New Category

Open an issue first to discuss whether a new category makes sense. We want to keep the list focused on codebase intelligence rather than expanding to all of software engineering.

## Code of Conduct

Be respectful. This is a collaborative resource for the engineering community.
